# Java AI 高级全能工程师

课程定位：融合 Java 企业后端、大模型应用开发、Agent 智能体、云原生部署的全能工程师培养课。依托 SpringAI 生态，在 Java 体系内落地 RAG、函数调用、多 Agent 业务系统，对接 DeepAgents、MCP、A2A、Skills 架构，结合 SDD 规范、Harness 安全护栏，适合有 Java 基础后端工程师、架构师转型 AI 业务开发。

## 阶段 1 Java 高阶企业级后端底座

- JVM 底层原理、GC 调优、内存模型、并发编程、CompletableFuture 异步
- SpringBoot3、SpringCloud 微服务，SpringAI 核心框架深度实战
- 中间件：MySQL 性能优化、Redis、Kafka/RocketMQ、Elasticsearch
- 分布式能力：分布式锁、限流熔断、分库分表、接口幂等、SkyWalking 链路追踪

## 阶段 2 LLM 大模型应用开发

- 提示工程、Token 管理、流式输出、多轮会话管理
- SpringAI 实战：对接通义、DeepSeek、Ollama 本地大模型，ChatClient 调用
- RAG 检索增强生成：文档解析、文本分块、向量库 Milvus/Chroma、私有知识库问答
- Function Calling 函数调用：大模型调用 Java 业务接口，查询数据库、拉取业务数据

## 阶段 3 Java 多 Agent 智能体开发【课程核心】

- 单 Agent 实现：记忆模块、工具调用、反思校验、Agent 状态持久化
- DeepAgents 集成：Java 服务作为业务调度中心，任务拆解生成 DAG 工作流
- MCP 协议：业务数据库、文件服务、业务 API 封装成 MCP 服务，供智能体安全调用
- A2A 智能体通信：不同业务 Agent 互相传递任务工件、同步执行状态
- Skills 可插拔技能：订单查询、报表生成、数据导出、数据校验封装为独立技能，动态加载

## 阶段 4 SDD 规范 + Harness 安全管控

- SDD 规范驱动：定义 AI 业务任务契约、接口规范、验收标准、禁止操作清单
- Harness 安全沙箱：Agent 业务操作隔离、权限分级、高危操作人工审批、操作审计、业务快照回滚
- 幻觉检测、输出过滤、敏感数据脱敏，降低 Agent 自主执行带来的业务风险

## 阶段 5 云原生与 LLMOps 部署运维

- Docker 打包 Java AI 应用、K8s 编排、GPU 资源调度
- CI/CD 流水线、灰度发布、日志采集、指标监控
- 对接 AIOps 体系，监控 Java 服务、模型接口延迟、错误率，异常智能诊断

## 阶段 6 大型综合实战项目

1. 企业私有 RAG 知识库问答系统（SpringAI + 向量库）
2. 多 Agent 智能客服系统，订单查询、售后、退款业务流转
3. 自然语言转 SQL 智能报表 Agent，自动查询数据库生成业务报表
4. 企业智能工作流平台，DeepAgents 编排多个 Java 业务 Agent 完成复杂审批流程

## 适合人群与前置

✅ 适合：Java 后端开发、微服务架构师，想要切入 AI 业务应用开发
📌 前置：掌握 Java 基础，SpringBoot 开发经验

## 能力边界

课程聚焦**大模型业务应用开发**，不做大模型底层预训练。大模型存在幻觉，资金、数据修改等高风险业务，必须启用 Harness 审批机制，不能完全交给 Agent 自动执行。
